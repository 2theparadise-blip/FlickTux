================================================================================
  Wacom Bamboo ペンタブレット使い方ガイド（ペン＆タッチ操作マニュアル）
================================================================================

このパソコン（Linux Mint）には、高性能なペンタブレット
「Wacom Bamboo Fun Pen & Touch（型番: CTH-470）」が接続されています。

このタブレットの最大の特徴は、
  * ペンを持てば【本格的なお絵かき・イラスト用ペンタブ】
  * 指で触れば【広々としたノートPC風のトラックパッド】
として、置くだけで自動的に切り替わってどちらも自由に使える点です！

1. 指でさわる！【トラックパッド（タッチ）操作】
--------------------------------------------------------------------------------
ペンを持っていないときは、タブレットの黒い面を「ノートPCのタッチパッド」
「Macのトラックパッド」と全く同じように指で操作できます。

■ 1本指でなぞる:
  * マウスポインタが指の動きに合わせてスイスイ動きます。

■ 1本指でトンとタップ:
  * 「左クリック」になります。アイコンを開いたりボタンを押したりできます。

■ 1本指でトン・トンと2回タップ:
  * 「ダブルクリック」になります。ファイルや動画を開けます。

■ 2本指でトンとタップ:
  * 「右クリック」になります。メニューが開きます。

■ 2本指で上下になぞる（スライド）:
  * 「画面スクロール」です。YouTubeやウェブサイト、長い文書をスルスル上下に
    スクロールして読めます。

■ 2本指でサッとスワイプ（上下に払う）:
  * 【新機能】「フリックキーボード（FlickTux）」のトグル起動・終了！
  * タブレット面を指2本でサッと上下に払うと、キーボードが瞬時に画面に現れます。
  * キーボードが表示されている時にもう一度2本指スワイプすると、即座に終了して消えます。

■ 2本指でつまむ・広げる（ピンチイン / ピンチアウト）:
  * 写真や地図、Web画面の「拡大」や「縮小」ができます。


--------------------------------------------------------------------------------
2. ペンで描く！【ペンタブレット操作】
--------------------------------------------------------------------------------
付属のペンをタブレット面に近づけると、自動で「ペンモード」になり、
指でのタッチは自動的に止まります（描いている最中に手のひらで誤作動しません）。

■ ペン先を浮かせて動かす:
  * ペン先を板から少し（数ミリ〜1cm）浮かせた状態で動かすと、ポインタが移動します。
  * 「絶対座標」なので、板の右上にペンを持っていくと画面の右上にピュッと移動します。

■ ペン先で板をトンと突く / なぞる:
  * 「左クリック」または「絵を描く（ドラッグ）」になります。

■ ペンの軸についているボタン（サイドスイッチ）:
  * 下側のボタン: 「右クリック」
  * 上側のボタン: 「中クリック」または「消しゴム切り替え」
  ※ ペンのサイドスイッチに「F12」を割り当てることで、ペンを持ったままワンタッチで
     FlickTux キーボードの出し入れも可能です。

■ ペンの後ろ側（お尻の部分）:
  * 鉛筆の後ろについている消しゴムのように、お尻を板に当ててこすると
    「消しゴム」として機能します。


--------------------------------------------------------------------------------
3. お絵かき・デザインアプリで使う【制作時はペン機能が100%優先！】
--------------------------------------------------------------------------------
PhotoCraft や VectorCraft などの制作ソフトを開いているときは、
お絵かきに集中できるよう【ペンタブ機能が自動的に最優先】になります！

■ ペンタブ優先モードの安心設計:
  * ペンで描いている最中に手のひらが当たっても、勝手に画面がスクロールしたり、
    タッチ誤認でキーボードが開くことはありません（パームリジェクション機能）。
  * 筆圧やペン先の動きに100%集中できます。

■ PhotoCraft（フォトクラフト / 写真編集・イラスト）:
  * ブラシツールを選んでペンで描くと、「筆圧（ペンの押し込み具合）」に
    応じて、線の太さや色の濃淡が本物の絵の具や鉛筆のように変化します。
  * 上部のバーにある筆圧ボタンをオンにして使います。

■ VectorCraft（ベクタークラフト / ロゴ・イラストデザイン）:
  * ブラシツール（Paintbrush）で「Use Pressure Pen」をオンにすると、
    強弱のついたきれいなベクターラインが描けます。


--------------------------------------------------------------------------------
4. フリック入力パネル（FlickTux: flktux）の出し入れ ＆ 特化型入力モード
--------------------------------------------------------------------------------
キーボードに手を伸ばさず、手元のタブレットだけで文字を打ちたいときに使います。
デスクトップを汚さないクリーン設計のため、画面下のDockやジェスチャーからいつでも呼び出せます。

■ 出し方・消し方（トグル開閉）:
  * 【指タッチ操作の場合（最速）】: タブレット面を「指3本でサッとスワイプ（全方向対応）」する
    → 画面上にスッと現れます。
    → キーボード起動中にもう一度「3本指スワイプ」すると、即座に終了して消えます。
    ※ 2本指スクロールや1本指ポインタ移動と競合しない安心設計です。
  * 【キーボードの場合】: 「F12」キーを押す（ペンやタブレットキーへの割り当て推奨）
  * 【画面からの場合】: 画面下の Dock（Plank）に並んでいる「FlickTux」アイコンをクリックする
  * 【メニューからの場合】: スタートメニューの「アクセサリ」→「FlickTux」をクリックする
  * 【端末（黒い画面）の場合】: flktux toggle と打ってEnterを押す
  ※ 文字の入力先（点滅している縦棒）は元のアプリのまま変わりません。
  ※ 移動した位置は自動保存され、次回も同じ場所に現れます。ポインタ拘束がないため画面全体を自由に操作できます。

■ 特化型入力予測モード（codepredict）:
  上部バーのセレクターで、用途に応じた専用予測モードを選択・自動追従できます。
  * 【通常モード (general)】:
    日常会話、SNS、挨拶・定型句（「お疲れ様です」「ありがとうございます」「よろしくお願いします」等）をワンタップ入力。
  * 【ビジネス文書モード (business)】:
    ビジネスメール、日報、公式文書向け敬語スニペット（「いつもお世話になっております。」「ご確認いただけますと幸いです。」「【重要】」「担当：」等）。
  * 【小説・創作特化モード (novel)】:
    小説執筆向けの作法に準拠。カギ括弧（「」、ルビ《》等）を入力すると、自動でカーソルがカッコの内側へ復帰！
    三点リーダー「……」、ダッシュ「――」、感嘆疑問符＋全角空白（「！　」「？　」）もワンタップで展開。
  * 【Linuxコマンドモード (linux)】:
    sudo, systemctl, apt, git, docker, パイプ/リダイレクト（| grep, > /dev/null）を補完。
  * 【多言語コード補完】:
    Python, Rust, Bash, JavaScript, C++ の構文・予約語スニペット。

■ 筆圧手書き文字認識 ＆ 手書き文字スタンプ配置:
  * パネル上部の [ 手書き ] ボタンを押すと、手書きキャンバスが展開。
  * 【手書きキーボード入力】: 描いた文字を Linux zinnia エンジンで高精度認識し、文字コードとしてエディタに入力。
  * 【手書きスタンプ配置】: 描いたサインや文字を背景透過画像として自動切り抜き、ワンクリックでキャンバス上に直接貼り付け（Ctrl+V）。

■ 5大配列 ＆ 5大モード（かな / カナ / 英字 / 数字 / ナビ）:
  * 上部タブで [ Google ] [ Galaxy ] [ iPhone ] [ ガラケー ] [ 10キー ] を切り替え可能。
  * [切替] ボタンを押すと、【かな】➔【カナ】➔【英字】➔【数字】➔【ナビ (表計算)】が順繰りに切り替わります。

■ 10キー配列（縦5行×横4列）:
  * イラスト制作に最適な、PCテンキー・外付けテンキーと連動する配列です：
    - 7: あ / abc
    - 8: か / def
    - 9: さ / ghi
    - 4: た / jkl
    - 5: な / mno
    - 6: は / pqrs
    - 1: ま / tuv
    - 2: や / wxyz
    - 3: ら / @._/
    - 0: わ / 空白
    - .: 、。 / .,?!
    - *: ゛゜小 / a/A (大文字小文字切替)
    - +: 次へ (トグル確定)
    - Enter: 確定
  ※ 外付けテンキーを左手に持ち、右手でペンを持ちながら文字やタグを片手で即座に入力できます！

■ ペンタブ感度・筆圧設定センター (flktux-settings):
  * パネル上部の [ 設定 ] ボタン、またはメニューから起動。
  * 【イラスト・お絵描き】: 筆圧柔らかめ、手ブレ補正ON、16:9正円比率維持、指タッチOFF
  * 【超機敏・快速】: 遅延ゼロ、羽のように軽いクリック、指トラックパッド高速モード
  * 【試し書き広場】: 画面内でペンを描くと、筆圧に応じて線の太さがリアルタイムに変化し、描き心地をその場でテストできます。


--------------------------------------------------------------------------------
5. ペンタブ本体の４つのボタン（エクスプレスキー）
--------------------------------------------------------------------------------
タブレットの端（左側）に並んでいる4つのボタンは、制作ソフトやお絵描きでよく使う
便利なショートカットが割り当てられています。

  [ 上ボタン① ] : 元に戻す（取り消し / Ctrl + Z）
  [ 上ボタン② ] : やり直し（進む / Ctrl + Y）
  [ 下ボタン③ ] : スポイト（画面の色を吸い取る / Alt）
  [ 下ボタン④ ] : 画面の移動（手のひらツール / Space）

※ 左手でこのボタンをポチポチ押しながら、右手でペンを走らせるとプロのように
   サクサク絵が描けます！ボタンの1つを「F12」に設定してFlickTuxのトグルキーにするのもおすすめです。


================================================================================
  * 困ったときの Q & A
================================================================================
Q. ペンで描いているときに、手のひらが当たって反応してしまう！
A. ペン先をタブレットに近づけている間は自動で指タッチが止まる仕組みになって
   いますが、どうしても気になる場合は一時的に指タッチだけをOFFにできます。

   【指タッチのON / OFF 切り替え方法】:
   * 【一番かんたん】:
     端末（黒い画面）で wacom-touch-toggle と打ってEnterを押すだけで瞬時に切り替わります。
   * 【設定センターから】:
     flktux-settings の「イラスト・お絵描き」プロファイルを選ぶと、自動的に指タッチOFFになります。

Q. ペンの芯がすり減ってきたら？
A. 付属の替え芯をピンセットや毛抜きで引き抜いて、新しい芯を差し込むだけで
   誰でもかんたんに交換できます。
