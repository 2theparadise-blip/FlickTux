# FlickTux キー配列修正 & プッシュボタン12キー & 音声AI受話器連動 実装計画書

## 1. 概要と背景

本計画書は、以下の要件を満たすための完全な技術仕様と実装フェーズを定義します：

1. **スマートフォン3大フリック配列の忠実再現**:
   - **Google (Gboard 12キー 日本語)**: カーソル左右キーを左列に集約、右列にBS・空白・変換・確定を実機通りに配置
   - **iPhone (iOS 日本語かなフリック)**: 左列に `☆123`, `ABC`, `小 ゛゜`, `🌐`、右列に `⌫`, `空白`, `改行 (縦2段 rowSpan:2)`、サブフリックに実機特有の鉤括弧 `「` `」` を設定
   - **Galaxy (Samsung 日本語テンキー)**: 左列に機能キー、右列にBS・カーソル・確定を実機準拠で配置
2. **10キー配列の「あ」重複バグ修正**:
   - 確定ボタンの左隣（Row 4 Col 2）に表示されていた重複「あ」を **`.` (ピリオド/ドット)** に変更
3. **プッシュボタン配列の新設（基本12キー: 4行 x 3列）**:
   - ガラケー配列（4x5連打文字入力）とは完全に独立した、**電話機本来の物理12キー（1-2-3 / 4-5-6 / 7-8-9 / * 0 #）** をベースとするプッシュ電話配列プリセット (`push_phone` / 12キー) を新設
4. **キーマップ修正アプリ（Webエディタ）でのボタン増設（動的グリッド拡張）**:
   - 12キー、19キー、20キーなどの固定グリッドにとどまらず、**「行の追加」「列の追加」「セルの追加/削除」** によりユーザーが自由にボタン数を拡張・カスタマイズできるUIとデータ連携を実装
5. **プッシュ電話改造キーボード仕様：受話器フック連動（音声AIチャット起動）**:
   - プッシュ電話機を改造したキーボードにおいて、**受話器を持ち上げた（Off-hook）瞬間にユーザー指定の音声AIチャットを起動・接続**し、受話器を戻した（On-hook）時に終了するイベントトリガー機能を FlickTux に搭載

## 2. キー配列詳細設計マトリックス

### 2.1 Google (Gboard 日本語 12キー) 忠実再現 (4行 x 5列)

| 行 \ 列 | Col 0 (左機能) | Col 1 (テンキー左) | Col 2 (テンキー中) | Col 3 (テンキー右) | Col 4 (右機能) |
|:---:|:---:|:---:|:---:|:---:|
| **Row 0** | **文字切替** (`あ`) | **あ** | **か** | **さ** | **⌫** (BS) |
| **Row 1** | **◀** (カーソル左) | **た** | **な** | **は** | **空白** (Space) |
| **Row 2** | **▶** (カーソル右) | **ま** | **や** | **ら** | **変換** (Convert) |
| **Row 3** | **記号** (`?123`) | **゛゜小** (濁点) | **わ** | **、。** (句読点) | **確定** (Enter) |

- サブフリック: `や` = `（` `）`, `わ` = `を/ん/ー/〜`, `、。` = `。/？/！/…`

### 2.4 10キー配列（電卓式: 7-8-9上段）の「あ」重複解消 (5行 x 4列)

| 行 \ 列 | Col 0 | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| **Row 0** | **記号** (/) | **◀** (←) | **▶** (→) | **⌫** (BS) |
| **Row 1** | **あ** (7) | **か** (8) | **さ** (9) | **空白** (-) |
| **Row 2** | **た** (4) | **な** (5) | **は** (6) | **変換** (変) |
| **Row 3** | **ま** (1) | **や** (2) | **ら** (3) | **次へ** (+) |
| **Row 4** | **わ** (0) | **切替** (モード) | **.** (.) *(←修正)* | **確定** (Ent) |

### 2.5 プッシュボタン配列（基本12キー: 4行 x 3列）新設

固定電話（プッシュホン）の物理12キーに完全準拠したダイヤルパッド配列。

| 行 \ 列 | Col 0 | Col 1 | Col 2 |
|:---:|:---:|:---:|:---:|
| **Row 0** | **あ** (1) | **か** (2) | **さ** (3) |
| **Row 1** | **た** (4) | **な** (5) | **は** (6) |
| **Row 2** | **ま** (7) | **や** (8) | **ら** (9) |
| **Row 3** | **小 / 切替** (*) | **わ** (0) | **確定 / 記号** (#) |

- **フリック機能**: 各キーは中央タップで数字/基本文字、上下左右フリックでかな文字/記号を展開
- **拡張性**: この12キーをベースに、Webエディタでボタンや列を増設可能

## 3. キーマップ修正アプリでの「ボタン増設（グリッド拡張）」機能

Webエディタ (`web/index.html`) に動的なグリッド編集コントロールを追加します：

1. **コントロールボタン群の追加**:
   - `[➕ 行を追加 (Add Row)]`: グリッドの最下部（または指定位置）に空セル行を追加
   - `[➖ 行を削除 (Remove Row)]`: 末尾行を削除
   - `[➕ 列を追加 (Add Column)]`: グリッドの右端に新しい機能列を追加（12キー → 16キー → 20キーへ拡張可能）
   - `[➖ 列を削除 (Remove Column)]`: 右端列を削除
2. **セル結合・分割制御**:
   - 既存の `rowSpan`, `colSpan` に加え、空セルを即座に新規キー（Flick / Action）に割り当て
3. **データ永続化**:
   - 動的に拡張された `rows` x `cols` マトリックスを JSON として `/api/presets/custom` に保存し、即座に Rust コアエンジンへ反映

## 4. プッシュ電話改造キーボード仕様：受話器フック連動（音声AIチャット接続）

### 4.1 動作シーケンス
1. **Off-hook（受話器を上げる）**:
   - 電話機のフック（マイクロスイッチ / リードスイッチ）が作動
   - evdev（キーイベント `KEY_PHONE` / マウスボタン / GPIO / シリアル等）として FlickTux が検出
   - 設定された **音声AIチャット起動コマンド** を即座に非同期実行
   - （例: ブラウザで ChatGPT Voice / Gemini Live 画面を開く、またはローカル音声対話デーモンと接続）
2. **On-hook（受話器を置く）**:
   - フックスイッチが戻る
   - 通話終了コマンド（または音声AIウィンドウの終了・ミュート処理）を実行

### 4.2 設定スキーマ (`configs/config.json`)
```json
{
  "hook_trigger": {
    "enabled": true,
    "input_device": "/dev/input/by-id/usb-telephone-hook-event",
    "event_type": "EV_KEY",
    "event_code": "KEY_PHONE",
    "on_offhook": "xdg-open 'https://gemini.google.com' || /usr/local/bin/start_voice_ai.sh",
    "on_onhook": "pkill -f voice_ai || /usr/local/bin/stop_voice_ai.sh"
  }
}
```
