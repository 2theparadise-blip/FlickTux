# プロジェクト仕様書：ポータブル・サイバーデッキ＆タクティカル・ガジェットスイート
**コードネーム：** オペレーション・ゴーストネット（UNIT-2011/5）
**分類：** フィールド・オパレーティブ・サイバーウェア＆映画プロップ設計書
**想定効果：** 高いオークション価値と実用性を兼ね備えた、インタラクティブで重厚なサイバーパンクSFプロップ。

## 1. デザインテーマとマテリアル哲学
重量のある実 metal 構造は避け、軽量かつ高剛性な**「ハリウッド・プロップ・エンジニアリング（ハリボテ錬金術）」**アプローチを採用します。

*   **コア・マテリアル・マトリックス：**
    *   **プラ板（プラペーパー）：** メインの箱組み筐体、カスタム制御フェンス、構造エンクロージャーに使用。加工・塗装・ウェザリングが容易。
    *   **薄手アルミ板（0.3mm - 0.5mm）：** 高接触エリア、排熱スリット、シリアルプレートに貼付し、本物の金属的な冷たさと触感（タクタイル）を付与。
    *   **高硬度ウレタンフォーム / EVAボード：** 衝撃吸収バンパー、腕・手首のエルゴノミクス・パッド、ハーネス基部に使用。オリーブドラブやマットブラックで塗装し、ステンシル文字（`[IMPACT ABSORBER // TYPE-04]`）をマーキング。
*   **ウェザリングと仕上げ：**
    *   下地にメタリックシルバーを塗り、その上からマットなタクティカルグレー／ブラックを重ね、角を紙やすりで削る「チッピング技法」で長年使い込まれたストリートの経年変化を再現。

## 2. ハードウェア・アーキテクチャ：2系統のモジュラー戦略
「すべてを1つの箱に詰め込まない」モジュラー思想に基づき、用途別に最適化したデバイスを展開します。

### [モデル 1] リストマウント型ガントレット（タッチ板フリック式）
*   **フォームファクター：** 前腕（手首〜肘）にピタッと沿う、オイルドレザーと真鍮リベットのハーネス付きスリムガントレット。
*   **入力方式：** タッチ板（またはトラックパッド）による「SF風フリック入力」＆ペンジェスチャー。
*   **主要ギミック：**
    *   **フリップアップ装甲バイザー：** スモークアクリル製の開閉式カバー。ロックを外すとバネで跳ね上がり、内部マイクロスイッチで画面が起動。
    *   **方向ベクトルLED：** タッチ板のフチに埋め込まれ、指のフリック方向に合わせて閃光が流れる。
    *   **ボンネット／サイド展開堰体：** パッチン錠（トグルラッチ）でガバッと開き、内部のラズパイ・カートリッジや巻き取り式ケーブルにアクセス可能。

### [モデル 2] モジュラー・ペリフェラル・スイート（周辺ガジェット群）
デッキ本体の堰体内に隠された**「巻き取り式自動リールケーブル（ゴツいミリタリープラグ仕様）」**で直結する、取り外し可能な単体マイコン・ガジェット群。

## 3. モジュラー・ガジェット・マニフェスト

### ガジェット ①：`SIGNAL LEECH // シグナル・リーチ` (ESP32 Wi-Fiスニッファー)
*   **ベースハードウェア：** ESP32 / ESP8266 ＋ 1.3インチ緑/アンバーOLED ＋ 折りたたみ式SMAアンテナ。
*   **最低限の実用性：** 周囲に飛んでいる実際のWi-FiのSSID、MACアドレス、電波強度（RSSI）をリアルタイムでスキャン・表示。
*   **SFハッタリ・ギミック：** 物理トリガーを押すと `[CRACKING MODE : WPA3-BYPASS]` が起動。16進数コードの高速スクロール、8連LEDバーグラフの明滅、完了アラート（`[HANDSHAKE CAPTURED]`）が動作。

### ガジェット ②：`GHOST PAY // ゴースト・ペイ` (ICチップ決済スキマー)
*   **ベースハードウェア：** Arduino Nano ＋ 期限切れカード等から切り抜いた「金色のIC contactパッド」 ＋ ミニ液晶。
*   **最低限の実用性：** 内部のウレタン層に本物の交通系ICカード等を忍ばせ、実用的な非接触パスとしても機能。
*   **SFハッタリ・ギミック：** ロータリースイッチで複数の違法ID（`[SLOT 1: CORP_BANK]`等）を切り替え。トリガーを引くと残高が `¥ 420` ➔ `¥ 9,999,999 [LOCKED]` へ跳ね上がる改ざんアニメーションが作動。

### ガジェット ③：`THUMB SPOOFER // サム・スプーファー` (生体バイパスユニット)
*   **ハードウェア：** 透明シリコン製のダミー指紋パッド ＋ 内部の赤色LED ＋ マイクロ振動モーター。
*   **ギミック：** センサーや対象に押し当てて押すと、赤色LEDが点滅し、手元にブルッと確かなハプティクス（振動）が伝わるオーバーライド演出。

## 4. アパレル・フィールド統合（タクティカル衣装の連携）
*   **コスチュームコンセプト：** 多重ポケットを備えたサイバーパンク／ミリタリーテックウェア（カーゴパンツ、ユーティリティベスト）。
*   **装備の懸架（マウント）：**
    *   デッキ本体や周辺ガジェット（`SIGNAL LEECH`, `GHOST PAY`等）は、衣装の各ポケットや、ガントレット側面のマグネット・ハードポイントにガチャンと着脱可能。
    *   現場に到着したら、ポケットからガジェットを引き抜き、巻き取り式ケーブルをシュルッと伸ばしてデッキに直結する「現場ハッキング」のアクションを完結させる。
